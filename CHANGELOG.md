# Changelog

All notable changes to fs-9p are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html): a change to the
command line or to documented behaviour that breaks an existing setup bumps
the major version (the minor version while it is 0.x), new options or
behaviour bump the minor version, fixes bump the patch version.

The version itself is set in one place, `CMakeLists.txt`; see the Developer
Guide, "Making a release".
